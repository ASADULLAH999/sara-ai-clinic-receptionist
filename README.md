# Sara: AI Receptionist for Clinics 🤖

A WhatsApp AI receptionist that handles clinic appointment conversations 24/7.

## What Sara does
- Replies to patients on WhatsApp in a natural, context-aware conversation
- Understands the patient's request
- Checks doctor availability
- Collects the required patient details
- Books the appointment and sends a confirmation
- Saves every record automatically in the database
- Sends appointment reminders and a confirmation email
- Hands complex or sensitive cases over to human staff

## Workflow
WhatsApp → AI Receptionist → Availability → Patient Details → Confirmation → Database → Human Handoff

## Tech Stack
OpenClaw · WhatsApp API · LLM integration · Database · Email automation

## Why I built it
Most clinic receptionists spend their day replying to the same appointment messages. Sara takes that repetitive work off the team so staff can focus on patients.
